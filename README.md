# Smart Bank Management & Customer Analytics System

B.Sc. Data Science final-year project using Python, Flask, SQLite, Pandas and Scikit-learn.

## Features
- Admin login
- Customer registration
- Account creation
- Deposit and withdrawal
- Fund transfer
- Transaction history
- Analytics dashboard
- K-Means customer segmentation
- Basic fraud-risk flagging rules
- SQLite database



## Run on Windows
```text
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Then open: http://127.0.0.1:5000/

This is an educational prototype, not production banking software. Do not use real customer or banking data.
